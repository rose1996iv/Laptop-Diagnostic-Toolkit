# In-Store Checklist

1. Confirm the exact model and seller specification.
2. Run Quick Scan and verify CPU, RAM, GPU, VRAM, storage, and display.
3. Load an expected profile when one is available.
4. Confirm the dedicated GPU is distinct from integrated graphics.
5. Check display resolution and refresh rate.
6. Inspect the screen using solid colors and a grid.
7. Run the bounded complete scan only after reading its warning.
8. Review battery availability and health limitations.
9. Check keyboard, touchpad, ports, camera, microphone, speakers, charger, hinge, and body.
10. Export JSON and HTML reports.

The toolkit is a recommendation aid, not proof that hidden defects do not exist. Never use it for destructive disk, firmware, BIOS, or security changes.
